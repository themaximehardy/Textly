# Code of conduct

Textly is a small, friendly project. Everyone is welcome, whatever their experience, background or the languages they write in.

**Do**
- Be kind and assume good intent.
- Give feedback on the work, not the person.
- Help newcomers.

**Don't**
- Harass, insult or demean anyone.
- Post other people's private information.
- Keep going after someone has asked you to stop.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block people who keep breaking them.

To report a problem privately, use the email on the maintainer's GitHub profile.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
